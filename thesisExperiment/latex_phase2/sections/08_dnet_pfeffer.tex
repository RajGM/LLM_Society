\section{D-net, Pfeffer observables, and Debnath}
\label{sec:dnet}

The D-net arm imports a reconstructed graph and runs the same two scoring modes on homogeneous conspiracy and mixed identities.
The empirical file is \path{thesisExperiment/data/derived/debnath_hashtag_cascade.json}.
Kind: hashtag co-occurrence.
\texttt{notARetweetCascade: true}.
Nodes are users keyed by published hashtags (63 nodes, 228 directed edges).
Edges reuse a \texttt{retweets[]} container only as a directed-edge slot.
The graph is not a hydrated retweet cascade and not a FakeNewsNet conversation tree.

Hydration of Debnath's tweet identifiers failed.
Mendeley \texttt{10.17632/546hsym93p.1} is an identifier dump, not tweet text \parencite{debnath2023dataset}.
OSF \texttt{dataset.csv} stores \texttt{tweet\_id} in Excel scientific notation, so low digits are gone; usable digit identifiers in the sampled prefix were zero.
No Twitter/X bearer was present.
814,924 tweets were not hydrated.
Belief profiles remain theory-faithful reductions, not skip-gram/HDBSCAN centroids \parencite{debnath2023conspiracy,geoeng2023codes}.

Debnath reports no empirical $0$--$5$ \MPR{}.
Simulated auditor \MI{} is therefore not Twitter \MI{}.
\textcite{ruths2014social} already warn that platform traces are not a transparent sample of behaviour; this comparison inherits that caution twice, because the empirical object is a hashtag fallback.

\subsection{Structural comparison}

\Cref{fig:dnet} and \Cref{tab:struct} compare empirical hashtag-graph metrics with the mean of 16 simulated D-net cascades.
Structural similarity (share of compared metrics within a 30\% band) is $0.6885$: breadth matches, depth and structural virality \parencite{goel2016virality} do not.
Size is informational only.

Kolmogorov--Smirnov tests use $n_{\mathrm{real}}=1$ and $n_{\mathrm{sim}}=16$.
Those tests are underpowered.
KS $p$-values (depth $0.1104$, breadth $0.2954$, virality $0.1104$) are not a twin-validation claim.
Jensen--Shannon divergence equals $1$ on all three metrics.
DTFS $=0.2754$ with \texttt{isValidated=false} (threshold $0.70$).
Content correlation is set to $0$ because Debnath has no empirical \MPR{}.

\subsection{Pfeffer 2014: seven factors, then a remapping}

\textcite{pfeffer2014firestorms} list seven interrelated factors in the Outlook section:
\begin{enumerate}[nosep]
\item speed and volume of communication;
\item binary choices (like/share/retweet as either--or);
\item network clusters;
\item unrestrained information flow;
\item lack of diversity;
\item cross-media dynamics;
\item network-triggered decision processes.
\end{enumerate}
That list is the primary theory.
The thesis six-knob vocabulary (valence, surprise, identity, clustering, echo, temporal acceleration) is a computational remapping, not a restatement of the 2014 paper.
\Cref{tab:pfeffer} records seven \emph{observables} so that the operational table matches the paper's count.
Cross-media remains held: no legacy-media broadcast agent exists in the engine.
Binary choices (factor~2) have no dedicated row, because the engine is ternary (forward/reinterpret/drop).
